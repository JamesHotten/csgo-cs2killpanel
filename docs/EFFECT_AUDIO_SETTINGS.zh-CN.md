# 特效与音效设置说明

本文说明 Kill Confirm Game Bar 当前版本中每个音效、动画和高级特效设置的作用、默认值、适用风格及回退规则。CS2、CS:GO Legacy 和带机器人 Mod 的 Legacy 共用这些显示与播放设置；区别只在击杀事件的来源。

完整的风格专用选项以 Game Bar 小组件中的“高级特效”面板为准；独立设置页主要用于全局显示、音频设备和运行维护选项。

## 如何开启和修改设置

1. 启动对应游戏后按 `Win + G` 打开 Xbox Game Bar。
2. 从小组件菜单打开 **Kill Confirm Overlay**，建议将其固定，确保关闭 Game Bar 面板后悬浮效果仍保持运行。
3. 确认小组件显示本地服务已连接，并且进入游戏后能收到最近的 GSI 数据。
4. 在小组件中选择“游戏风格”。选择 CF 或 VAL 后，“高级特效”会显示该风格的专用选项；其他风格会显示共享连杀窗口及奖励算法选项。
5. 在同一控制区域选择语音包、图标包和音量。音频输出设备、重载音频、亮度、对比度、帧率、窗口位置和缩放位于设置页。
6. 修改后使用小组件的测试菜单分别发送普通击杀、爆头、刀杀、首杀、尾杀、助攻和多杀事件。设置会立即生效，不需要重启游戏。

“助攻音效”等开关只控制相应事件的播放方式，不负责开启游戏事件接收。CS2、Legacy、接管机器人及 Legacy Server 的事件接入方法参见 [CS2 与 CS:GO Legacy 迁移和使用说明](CS2_AND_LEGACY_MIGRATION.zh-CN.md#31-各场景快速开启检查表)。

## 风格、图标包和语音包

### 游戏风格

风格决定动画渲染器、信息布局和可选择的内置包：

| 风格 | 主要表现 | 连杀上限表现 |
|---|---|---|
| CF | CF 击杀图标、首杀/尾杀徽章、精英和武器叠层 | 图标六杀封顶；语音八杀封顶 |
| VAL | VAL 圆环、徽记、粒子和终结阶段 | 视觉支持一至六杀；六杀以上沿用六杀，音效五杀封顶 |
| CSOL | CSOL 一至十杀主图、首/尾杀、复仇、爆头、刀杀和助攻图标 | 一至十杀分别显示；十杀以上沿用十杀 |
| Battlefield 1 | 击杀卡、目标名称、武器和奖励信息 | 连杀次数影响累计逻辑，不切换分级语音 |
| Battlefield 5 | 滚动击杀图标及奖励信息 | 同上 |
| Battlefield 4 | BF4 HUD 风格文字与奖励信息 | 同上 |
| Battlefield 2042 | 2042 击杀图标、故障效果和奖励信息 | 同上 |
| PUBG | PUBG 滚动信息和击杀图标 | 同上 |
| 三角洲行动 | 三角洲击杀、助攻、载具、目标和奖励信息 | 同上 |

切换风格后，小组件会自动切换到该风格可见的图标包和语音包。每种风格的连杀窗口、动画位置和缩放分别保存，不会直接覆盖其他风格。

语音包和图标包选择采用三层兼容保存：每种风格的独立设置键、旧版本共享键以及 LocalState 文本备份。正常情况下读取独立设置；设置丢失或不可用时会从备份恢复，且不会把一个风格的包套用到另一个风格。

### 语音包

选择服务播放的声音集合。内置 CF 包包括 SWAT、飞虎队、女性、兔女郎、审判者和 American Girl；VAL 包与相同名称的视觉包对应；其他风格使用各自的固定音效包。

自定义语音包支持：

| 文件 | 作用 |
|---|---|
| `common.wav/.mp3/.m4a` | 普通一杀或通用击杀音 |
| `2`–`8` | 二杀至八杀语音；超过八杀沿用八杀 |
| `headshot` | 爆头音效 |
| `knife` | 刀杀音效 |
| `firstandlast` | 首杀和尾杀音效 |
| `common_overlay` | 与本次击杀音同时叠加的通用层 |
| `sound.lua` | 自定义高级路由；存在时优先使用脚本 |

缺少某个可选文件时，自动生成的路由只跳过该层，不会使其他已存在的声音失效。自定义 `sound.lua` 返回不存在或无法解码的文件时，服务日志会记录错误。

### 图标包

选择当前风格的主视觉素材。CF 内置包包括 Original、VIP、Legacy、Angelic Beast 以及导入的自定义包；VAL 图标包与 VAL 皮肤动画对应；其他风格使用固定素材。

导入的 CF 图标包可以只提供主图。可选 FX、精英层或武器徽章缺失时，相关 `AUTO` 选项会关闭或回退；选择 `ORIG` 可强制使用内置原版叠层，因此不会因为自定义包不完整而完全无图标。

## CF 专用高级设置

### 连杀计算

| 设置 | 作用 |
|---|---|
| 无连杀窗口 | 每次独立击杀按一杀处理，不把相邻击杀合并为二杀以上 |
| 死亡前持续累计（默认） | 从存活开始持续累计，死亡、回合切换或观察目标身份变化时重置 |
| 自定义窗口 | 两次击杀间隔不超过 0.1–300 秒时继续累计 |
| 5/10/15 秒窗口 | 使用固定间隔累计；超时后的下一次击杀重新从一杀开始 |

观察、回放或接管机器人时，每个被观察玩家拥有独立基线；切换玩家不会继承前一个玩家的击杀或助攻差值。

### 爆头音效优先级

- `连杀优先`（默认）：二杀以上同时是爆头时播放二杀/三杀等连杀语音。
- `爆头优先`：二杀以上同时是爆头时，把音效路由到爆头音；动画图标不受这个设置影响。

### 刀杀音效优先级

- `刀杀优先`（默认）：二杀以上同时是刀杀时播放刀杀音。
- `连杀优先`：保留二杀/三杀等连杀语音。

### 爆头图标优先级

- `连杀优先`（默认）：二杀以上爆头显示对应连杀主图。
- `爆头优先`：改为爆头主图；若同时属于首杀或尾杀，则使用黄金爆头主图。

### 刀杀图标优先级

- `刀杀优先`（默认）：二杀以上刀杀显示刀杀主图。
- `连杀优先`：显示对应连杀主图。

若同一事件同时被识别为刀杀和爆头，CF 主图按刀杀分支优先。正常 CS 数据中这种组合很少出现。

### 首杀音效

- `特殊音效`（默认）：使用当前 CF 包的首杀音。大多数 CF 包以 `grenade.wav` 作为首杀/尾杀语音；American Girl 使用 `firstandlast.wav` 并叠加通用层。
- `原击杀音效`：不传递首杀音效标记，按普通一杀、爆头或刀杀规则播放。

首杀徽章属于独立视觉层，不会因为关闭首杀特殊音效而消失。

### 尾杀音效

- `特殊音效`（默认）：使用当前 CF 包的尾杀特殊音。
- `原击杀音效`：按本次实际连杀、爆头或刀杀规则播放。

尾杀徽章属于独立视觉层。尾杀事件不会再额外生成一次一杀动画或音效。

### 助攻音效

- `无声音`（默认）：助攻仍可显示支持的视觉提示，但不播放 CF 击杀语音。
- `有声音（common）`：按当前语音包的一杀/通用音播放，不增加击杀连杀计数。

### 击杀特效（Kill FX）

仅用于 CF 代码渲染图标：

- `AUTO`：使用当前图标包提供的二杀至六杀 FX；内置包使用对应内置效果。
- `OFF`：关闭连杀主图周围的额外 FX 层，主图仍显示。
- `ORIG`：强制使用原版内置 FX，适合自定义包没有 FX 的情况。

一杀、爆头、刀杀、首杀、尾杀和助攻没有二至六杀的通用 FX 层，因此该设置不会凭空给这些图标增加 FX。

### 精英特效

- `OFF`：不显示精英升级叠层。
- `Elite 1/2/3`：显示当前包的 1–3 级精英层；刀杀主图也会切换到对应等级的精英刀杀图标。
- `Orig 1/2/3`：导入包场景下强制使用原版 1–3 级精英素材。

精英层只叠加在 `multi1`–`multi6` 主图上；特殊爆头、首杀和尾杀徽章不使用该叠层。

### 附加武器图标

- `AUTO`：按击杀武器类别显示 Assault、Elite、Scout、Sniper 或 Knife 徽章。
- `OFF`：关闭附加武器徽章。
- `ORIG`：强制使用原版武器徽章。

武器徽章仅叠加在一至六杀主图上。后端在击杀发生时保存实际开火武器，因此击杀后快速切枪不会把徽章改成切换后的武器。

### 主图动画

- `Style 1`：完整进入、停留和退出动画。
- `Style 2`：使用第二套较简化的主图进入方式。

该设置只改变 CF 代码渲染主图的运动方式，不改变音效、击杀判定或 Legacy 序列帧素材。

## VAL 专用设置

### 连杀计算

含义与 CF 相同，支持无窗口、死亡前累计、自定义 0.1–300 秒和固定 5/10/15 秒。第五杀及以上使用五杀音效；视觉渲染保留第六杀终结阶段并在更高计数时封顶。

### 助攻音效

- `无声音`（默认）：VAL 助攻不播放击杀音。
- `有声音（common）`：播放当前 VAL 包的一杀音，不改变击杀计数。

VAL 当前没有独立助攻动画素材，因此这个开关只控制音频。

## CSOL 专用设置

CSOL 使用独立的 `csol4` 语音包和 `Csol4` 图标资源。连杀语音覆盖 1～10 杀；爆头、刀杀、首尾杀和助攻均有独立声音与图标。

- `语音优先级`：选择特殊击杀（爆头/刀杀）优先，或连杀次数语音优先；只改变音效，不改变视觉事件标记。
- `1杀/4杀/刀杀/首尾杀语音`：可固定到指定变体，也可保持随机。
- `首尾杀图标`：尾杀可使用复仇或首杀图标；首杀本身仍使用首杀图标。
- `连杀计算`：与共享连杀设置一致，支持死亡前累计、无窗口、自定义窗口和 5/10/15 秒窗口。

## 通用事件音效路由

BF1、BFV、BF4、BF2042 和三角洲的高级面板提供普通击杀、爆头、刀杀、助攻四条独立路由：

| 模式 | 作用 |
|---|---|
| 事件默认声音 | 使用当前风格原有 Lua 路由 |
| 普通击杀声音 | 只把本次音频改成普通一杀声音 |
| 自定义音频 | 播放复制到应用数据目录的 WAV、MP3 或 M4A 文件 |

路由只修改服务端音频上下文。爆头、刀杀、助攻、击杀次数、经济奖励和动画数据保持不变；回合胜负、炸弹、救人质等非战斗事件不会误用击杀路由。CF、VAL、PUBG 和 CSOL 保留各自专用音效算法。

## Battlefield、PUBG 和三角洲设置

这些风格均支持独立连杀窗口。高级面板还可选择奖励显示算法：

- `rules`（默认）：按当前游戏（CS2 或 CS:GO Legacy）的模式、武器、回合胜负、连败补偿和目标事件规则计算；非经济模式不显示奖励。两代游戏会分别采用自己的经济版本，例如 Legacy 保留 CZ75-Auto `$100`、XM1014 `$900`、Zeus `$0`，以及竞技/搭档下包后被拆弹 `$800` 的旧规则；CS2 对应为 `$300`、`$600`、`$100` 和 `$600`，并在竞技/搭档回合结算中为 CT 加入每消灭一名 T、每人 `$50` 的团队奖（休闲金额按各自规则折半或使用固定值）。
- `delta`：优先显示 GSI 观察到的实际金钱差值，能识别 CS2 CT 团队奖的 `$50` 阶梯、`$1000` 短缺收入及两者组合；无法归因时不把无关现金变化误当作击杀奖励。

CS2 的助攻只计入计分板助攻/贡献分，不会直接给予玩家金钱。因此所有风格的助攻只显示“助攻”提示，不显示 `+$`，也不会加入当前回合的经济奖励累计；该规则同时适用于 `rules` 和 `delta` 算法。

完整的两代游戏奖励矩阵、回合胜负和连败边界见 [CS2 与 CS:GO Legacy 经济奖励规则](CS2_CSGO_ECONOMY_RULES.zh-CN.md)。

各风格的音频设计不同：

| 风格 | 普通/特殊音频规则 |
|---|---|
| BF1 | 普通击杀音；爆头使用专用爆头音 |
| BF5 | 普通、爆头和摧毁载具有不同声音 |
| BF4 | 主要播放获得分数/奖励的提示音，没有分级击杀语音 |
| BF2042 | 普通和爆头有声音；助攻、回合胜利和失败设计为静音 |
| PUBG | 当前内置声音包设计为静音，只显示 PUBG 视觉信息 |
| 三角洲 | 普通、爆头、刀杀暴击、助攻、摧毁载具和得分均有对应声音 |

因此 BF2042 助攻/回合结算或 PUBG 全局无插件音效属于预期设置，不是素材加载失败。若希望这些风格有声音，可以导入自定义语音包并提供自己的 `sound.lua` 路由。

## 全局画面设置

设置主页将观察类事件拆成三个默认开启的开关：

- `观战队友效果`：控制普通观战其他玩家的 GSI 击杀和助攻。
- `回放视角效果`：控制带本地玩家状态的回放/观察视角事件。
- `接管机器人效果`：控制 CS2 本地日志 Bridge 与 Legacy Bridge 转发的接管击杀。

关闭任一开关时仍会更新对应来源的去重时间和独立基线，因此重新开启时不会补播历史击杀。本地玩家正常视角不受这些开关影响。旧版单一“观战玩家击杀效果”值会自动迁移到三个开关；设置页可将全部非敏感设置导出为带配置版本的 JSON，导入时先完整校验再写入并执行版本迁移。服务认证令牌和本机文件夹访问令牌不会被导出。

| 设置 | 范围 | 作用 |
|---|---:|---|
| 默认尺寸 | 550×600 | 请求 Game Bar 把小组件恢复到默认尺寸 |
| 动画居中 | — | 把击杀动画放回小组件内部中央，不移动小组件窗口 |
| 小组件居中 | — | 请求 Game Bar 把整个小组件窗口移动到当前屏幕中央 |
| 下方显示 | — | 把动画基准位置放到窗口下方约四分之一处 |
| 上移/下移 | 每次 12 像素 | 微调当前风格的动画纵向偏移 |
| 缩小/放大 | 每次 ×0.9/×1.1 | 调整当前风格动画缩放，内部限制为 0.35–3.0 倍 |
| 亮度 | 0%–100% | 增加动画贴图亮度；0% 为关闭增强 |
| 对比度 | 0%–100% | 增加动画贴图对比度；0% 为关闭增强 |
| 播放 FPS | 30–120 | 控制动画刷新目标帧率；素材本身的持续时间不变 |
| 控制面板缩放 | 自动/100%–200% | 只缩放 Game Bar 控制面板和点击区域，不改变击杀动画设置；自动模式按屏幕分辨率与 Windows 缩放选择 |
| 重置视觉 | — | 恢复亮度、对比度、位置和缩放的默认值 |

亮度、对比度或图标包变化会使资源缓存代次失效并串行重新加载，避免旧包的异步贴图混入新包；不影响音效。高 DPI 下 Win2D 画布还会按像素尺寸和面积限制内部渲染倍率，防止 2K/4K 缩放造成超大画布。

## 全局音频设置

### 音量

范围 0%–200%，默认 100%。这是插件自身的主音量：

- 0%：插件静音，但动画仍显示。
- 100%：素材基准音量。
- 110%–200%：额外增益，可能导致削波或听感失真，应按具体音效包调整。

不同内置 CF 包还带有代码中的响度补偿，用来缩小原素材之间的音量差异。

### 音频输出

- `系统默认`：服务启动或切换时使用 Windows 当前默认输出设备。
- 指定设备：固定到设置页列出的设备；设备消失时服务回退到系统默认设备。

“重载音频”会重建输出流，用于蓝牙耳机重连、默认设备变化或 Windows 音频服务恢复后重新取得声音。

## 测试预设

小组件中的测试菜单可以发送：普通一杀、爆头、刀杀、首杀、尾杀、助攻、黄金首/尾杀、二至九杀，以及只显示首杀/尾杀徽章的事件。“测试当前风格全部事件”按钮会按该风格的连杀上限依次发送首杀、连杀、爆头、刀杀、助攻、尾杀、回合胜利和回合失败。

建议修改设置后按以下顺序检查：

1. 选择当前游戏风格、语音包和图标包。
2. 先测试普通一杀、爆头和刀杀。
3. 测试二杀、五杀、六杀和九杀，确认封顶和连杀优先级。
4. 测试首杀、尾杀和助攻。
5. CF 再分别切换音效优先级、图标优先级、FX、精英层和武器徽章。
6. 如果动画正常但无声，检查插件音量、Windows 应用音量、输出设备，并执行“重载音频”。

测试按钮验证渲染与播放链路，但不会修改真实游戏击杀统计。

## 素材缺失时的行为

- 内置素材缺失：自动审查和构建应直接失败，不应发布该包。
- 导入 CF 图标包缺少可选 FX/精英/武器层：`AUTO` 跳过缺失层，`ORIG` 使用内置原版。
- 自定义语音包缺少某个特殊音：自动生成路由跳过该音；其他声音仍可播放。
- 自定义 Lua 返回错误文件：本次声音可能不播放，运行日志会记录具体路径和解码错误。
- 输出设备不存在：自动回退到 Windows 默认输出设备。
