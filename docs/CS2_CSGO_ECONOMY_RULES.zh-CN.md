# CS2 与 CS:GO Legacy 经济奖励规则

本文说明小组件奖励显示所采用的规则。数值来自当前安装的 CS2 与 CS:GO Legacy 模式 CFG、Legacy `items_game.txt`，并与 Valve 更新记录交叉核对。

已逐项比较两代游戏的竞技、搭档和休闲 CFG，每个模式各核对 26 个 `cash_*`、初始金钱及金钱上限字段。CFG 中的基础回合胜利、基础失败、连败阶梯、炸弹个人下包/拆弹、人质个人/团队奖励以及短缺收入数值相同；竞技和搭档的 `cash_team_planted_bomb_but_defused` 不同（CS2 `$600`、Legacy `$800`）。但这不表示最终回合到账相同：Valve 在 2025-07-16 为 CS2 竞技模式增加了 CT 团队消灭奖励，Legacy 没有该项。

## 适用模式

只有休闲、竞技和搭档使用现金奖励显示。死亡竞赛、军备竞赛、爆破、训练、生存及自定义等模式不显示经济奖励，避免把分数、模式专用货币或服务器自定义规则误认为标准现金。

第三方平台通常以竞技模式上报，但服务器可以覆盖任意 `cash_*` 参数。此时 `delta` 比 `rules` 更接近服务器的实际设置。

## CS2 的 CT 团队消灭奖励

CS2 的竞技和搭档模式中，每消灭一名 T，CT 全队每人会在回合结算时额外得到 `$50`，无论该回合最终胜利还是失败。标准 5v5 每人最多 `$250`，搭档 2v2 每人最多 `$100`。CS:GO Legacy、休闲及其他模式没有这项奖励。

这笔钱是团队回合奖金，不是造成击杀者独享的武器击杀奖励。例如一名 CT 用 AK 击杀一名 T：击杀者个人获得 AK 的 `$300`，而每名 CT 在回合结束时另得 `$50`。

## 炸弹与人质个人/团队奖励

| 事件 | 竞技/搭档 | 休闲 | 两代差异 |
|---|---:|---:|---|
| 个人下包 | `$300` | `$200` | 无 |
| 个人拆弹 | `$300` | `$200` | 无 |
| T 方下包但最终被拆 | CS2 `$600`；Legacy `$800` | `$200` | 有 |
| 个人接触/携带人质 | `$300` | `$300` | 无 |
| 队伍接触人质 | `$600` | `$500` | 无 |
| 个人救出人质 | `$1000` | `$1000` | 无 |
| 队伍救出人质 | `$600` | `$0` | 无 |

因此接触人质时，执行者可能一次观察到竞技/搭档 `$900` 或休闲 `$800`；救出人质时，执行者可能观察到竞技/搭档 `$1600` 或休闲 `$1000`。服务会识别个人、队伍及合并到账三种情况。

## 回合胜利奖励

### 爆破地图

| 模式 | 歼灭/时间耗尽 | 炸弹爆炸/拆弹 |
|---|---:|---:|
| 竞技 | `$3250` | `$3500` |
| 搭档 | `$2750` | `$3000` |
| 休闲 | `$2700` | `$2700` |

### 人质地图

| 模式 | CT 歼灭 | T 歼灭 | CT 救出 | T 拖到时间结束 |
|---|---:|---:|---:|---:|
| 竞技 | `$3000` | `$3000` | `$2900` | `$3250` |
| 搭档 | `$2500` | `$2500` | `$2900` | `$2750` |
| 休闲 | `$2300` | `$2000` | `$3000` | `$2000` |

表中是基础回合胜利金额。Legacy 的最终回合奖励就是该基础值；CS2 的 CT 在竞技/搭档中还要加上本回合 `$50 × 已消灭 T 数`。因此两代基础值相同，实际到账可能不同。

## 回合失败与连败补偿

| 模式 | 连败阶梯 |
|---|---|
| 竞技 | `$1400 → $1900 → $2400 → $2900 → $3400` |
| 搭档 | `$2000 → $2300 → $2600 → $2900 → $3200` |
| 休闲 | 固定 `$2400` |

- 竞技等级与 GSI `consecutive_round_losses` 直接对应：等级 0 为 `$1400`，等级 1 为 `$1900`，等级 2 为 `$2400`，等级 3 为 `$2900`，等级 4 及以上为 `$3400`。
- 两代游戏的竞技半场都以等级 1 开始，因此手枪局失败通常得到 `$1900`；CS2 下包后被拆时通常是 `$1900 + $600 = $2500`，Legacy 则是 `$1900 + $800 = $2700`，下包者另有个人 `$300`。
- T 方已经下包但随后被拆弹时，在基础失败补偿上额外加入 CS2 `$600`、Legacy `$800`；休闲两代都是 `$200`。
- 爆破地图因时间耗尽而失败时，仍然存活的 T 玩家个人不获得失败补偿；已经死亡的 T 玩家正常获得当前连败补偿。
- CS2 的 CT 即使输掉回合，竞技/搭档中仍会获得 `$50 × 本回合已消灭 T 数`；Legacy 没有。
- 竞技和搭档中，服务器确认队伍满足短缺收入资格后，每名队员每回合另得 `$1000`，不区分胜负。GSI 不提供资格倒计时或确认标志，因此 `rules` 不猜测该奖励；`delta` 在实际金钱变化完整可见时会识别 `回合奖励 + $1000`。

## 初始与金钱上限

| 模式 | 初始金钱 | 上限 |
|---|---:|---:|
| 竞技 | `$800` | `$16000` |
| 搭档 | `$800` | `$8000` |
| 休闲 | `$1000` | `$10000` |

这些数值不会单独生成特效，只用于解释金钱差值被上限截断的情况。

## `rules` 与 `delta`

- `rules`：按 GSI 识别出的 CS2/Legacy、模式、武器、地图类型和回合结果使用上述固定规则；最适合官方默认配置。若 GSI 提供 `allplayers_state`，会把已死亡 T 精确计入 CS2 CT 团队奖；本地玩家数据看不到全队状态时，至少计入当前 CT 玩家自己确认的击杀数。
- `delta`：仅接受能与合法事件金额吻合的实际金钱变化，并在数据缺失或受金钱上限截断时回退到对应游戏的规则；能补齐 CS2 CT 团队奖的 `$50` 阶梯，也能识别实际到账的 `$1000` 短缺队伍奖励及两者组合。

队友伤害人质 `-$30`、击杀人质 `-$1000`、击杀队友 `-$300` 属于惩罚而不是奖励。目前小组件不会为这些行为生成正奖励特效。
